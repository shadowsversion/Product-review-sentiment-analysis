Product Review Sentiment Analysis is an NLP-driven machine learning web application developed by Vishal and Akshat to evaluate and classify raw customer feedback from e-commerce platforms like Amazon. With thousands of product reviews generated daily, manual analysis is practically impossible. This system bridges that gap by leveraging Natural Language Processing and Machine Learning to automatically analyze unstructured text and categorize user opinions into Positive, Negative, or Neutral sentiments.
The underlying pipeline processes raw text through a structured sequence of data transformations. It begins with raw inputs from a sample dataset (reviews.csv), which undergo automated text preprocessing—including lowercase normalization, noise removal, and special character stripping—to prepare the input for model evaluation. The cleaned text is then converted into numerical representation using TF-IDF (Term Frequency-Inverse Document Frequency) vectorization, mapping word importance across the corpus into machine-readable feature vectors. For sentiment prediction, the architecture utilizes a Logistic Regression classifier, selected for its speed, simplicity, and proven accuracy on high-dimensional text data.
The system is deployed via an interactive Streamlit web dashboard. Users can input any custom review text, trigger real-time evaluation, and receive an instant sentiment prediction. Beyond individual text evaluation, the dashboard presents aggregate visual charts, sentiment counts, and distribution metrics for comprehensive data exploration. Built as a scalable foundation, the framework can easily expand to integrate larger datasets, advanced language models like Naive Bayes or BERT, and aspect-based sentiment analysis to evaluate specific product features like battery life, build quality, and pricing.
